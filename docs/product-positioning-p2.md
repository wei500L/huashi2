# P2 产品定位表达

## 核心定位
- 品牌名保持 `EF.Transfer`。
- 中文定位统一为 `英法词汇迁移教学工作台`。
- P2 的主叙事不再是“多角色入口”，而是“教师个人工作台”。

## 目标用户
- 第一用户：教师个人。
- 第一首页：`/teacher/workspace`。
- 管理员仍保持 admin-first 入口，不与教师首页争抢默认入口。

## 三条价值支柱
1. 诊断学生英法迁移风险。
2. 组织可复用词汇内容。
3. 跟进教学干预闭环。

## 入口策略
- 登录页：从角色卡片切换为教师工作价值表达。
- 侧栏品牌区：`EF.Transfer` + `英法词汇迁移教学工作台`。
- 教师侧边栏第一项：`教师工作台`。
- `班级总览` 更名为 `班级与学生`。

## 教师首页结构
- 今日关注：待处理干预、待发布草稿、待清理导入批次、待补齐词表。
- 快速动作：模板草稿、词对、词表、干预、班级与学生。
- 内容资产概览：班级、学生、草稿、词汇资产。
- 班级动态：最近活跃班级。

## 页面文案原则
- 页面副标题必须说明当前页面在教师工作流里的作用。
- 避免“真实数据来自哪里”这类实现导向描述占据主文案。
- 结果页和列表页都必须明确下一步动作。
