# 题型 3（判断正误）设计决策：全 F 反应定势与处理方案

> 文档编号：TYPE3_DESIGN_DECISION
> 版本：V2 题库 / V3 问卷
> 状态：已确定执行方案 A；依据用户要求严格按照 0811 修改意见生成

## 1. 用户规则回顾

「题型 3：判断正误。题干必须严格为：`法语目标词 = 易混英文词的中文义`。不得再使用随机其他词义替代英文义，不得为了平衡 V/F 偷换模板。」

同时，四种题型共用同一选词规则：法语假朋友词典与专四词书交集，且法语词前 2–3 个核心义与易混英文词中文义**概念上完全不重合**（排除 `classe/class` 这类共享核心义的情况）。

## 2. 逻辑推论：在双条件成立时题型 3 必然全 F

- 条件一（题干固定）：题干陈述为「法语词 = 英文词的中文义」。
- 条件二（选词规则）：入选词的 TEM4 核心义与英文词中文义**完全不重合**。

若两条件同时成立，则对每一个入选词，题干中的等式必然为假：法语词的核心义 ≠ 英文词的中文义。因此：

> **在当前规则下，题型 3 的所有题目答案都将是 F（错误）。**

这不是实现缺陷，而是规则的自然推论。任何出现 V 答案的题，要么题干没有使用英文词中文义（违反条件一），要么该词语义重合度被误判（违反条件二）。

## 3. 全 F 带来的反应定势风险

1. **反应定势（response bias）**：被试若察觉全部答案为 F，可能不再认真阅读题干，直接勾选 F，使该题型测量失真。
2. **学业猜测效应**：全 F 模式在考试情境下会被当作"隐藏规则"快速习得，题组内部一致性信度虚高，但构念效度受损。
3. **与 V1 的可比性问题**：V1 的 P4T3 为混合 V/F（原文 `VVFFFFFFVV`），V3 题型 3 若全 F，两版本该维度不可直接比较（见《发布 runbook》中的可比性说明）。

## 4. 两个方案

### 方案 A：完全忠于用户规则 —— 题型 3 全部为 F（当前默认）

- 优点：与用户明文规则完全一致；选词规则、题干模板均无例外；可审计性最强。
- 代价：全 F 反应定势风险；该 section 的测量学质量需在数据分析阶段用反应时与点击轨迹辅助判断。
- 缓解措施（不改变题目答案）：
  - 记录每题反应时，全 F 快答模式（如整 section 平均反应时显著低于其他 section）作为数据质量 flag（现有 `FAST_ITEM` flag 机制可复用）；
  - 答题完成后向被试展示说明，避免事后反馈造成困惑；
  - 分析时将该 section 单独计分，不与 V1 混合。

### 方案 B：另设不计入假朋友候选池的真命题控制题（平衡反应）

- 在题型 3 之外增加**明确标注为 control** 的真命题题（如「法语 librairie 表示 书店」（V）——该词不在假朋友候选池，因为其英文义与法语义相同，属于同形同义词而非假朋友）。
- 关键约束：
  - control 题必须**明显标注**为 control（题干注明"本题为控制题"），不得伪装成同一选词规则下的正式题；
  - control 题不计入假朋友候选池，不计入题型 3 的计分维度；
  - 若未来启用，需要为 control 命题另行建立来源证据与独立批准流程（TEM4 词书同一页的义项）。
- 优点：平衡 V/F 分布，降低反应定势。
- 代价：与用户"题干必须严格为英文词中文义、不得偷换模板"的字面规则存在张力；增加审定工作量；control 题本身也可能被被试识别。

## 5. 当前状态与结论

- **默认执行方案 A**：题型 3 全部为 F。
- 未获用户明确批准前，**不得**把题型 3 改为混合真假，也**不得**悄悄加入未标注的 control 题。
- 用户已要求严格按照 0811 文档执行，因此采用方案 A，不再把全 F 视为内容审查阻塞项。
- 问卷内容可标记为 `APPROVED`；是否创建 release 仍属于独立发布操作。

## 6. 已确定事项

1. 执行方案 A：全部使用英语迁移义，答案自然为 F；
2. 不加入与文档选词原则冲突的真命题控制题；
3. 保留反应时与快速作答质量标记；
4. 内容批准不等于自动发布，release 仍需独立创建。
