# 法语专四假朋友题库生产规则

## 内容审查责任

- 生产题库不再输出 `LEXICAL_REVIEW_PENDING` 或 `PEDAGOGIC_REVIEW_PENDING`。
- 每个进入生产题库的目标词必须得到明确的 `APPROVED` 或 `EXCLUDED` 决定。
- 自动字符串规则仅用于初筛，不能单独证明语义完全不重合；最终决定必须检查概念上下位关系、转喻关系、跨词性同形义和现代常用义。
- 来源异常或存在多个合理答案时直接排除，不以“待人工确认”进入题库。

## 题型一至三

1. 目标词必须来自 TEM4 与假朋友词典交集。
2. 法语词 TEM4 前 2–3 个义项与易混英语词中文义必须概念完全不重合。
3. 若英语迁移义同时也是该法语拼写的其他常用词性或常用义，排除该词，避免多答案。
4. 题型一的两个随机干扰项必须与目标词保持相同粗粒度词性，且不得与正确义或迁移义重合。
5. 题型二必须有完整可定位 TEM4 原句、来源支持的近义表达和英语迁移义对应法语表达；四个选项使用平行表达形式。
6. 假朋友题固定使用英语迁移义，答案为 F；另加入 10 道英法同形同义控制题，答案为 V，并以 `transferCategory=COGNATE` 独立标记后穿插展示。
7. Vrai 控制题不得伪装成假朋友：必须来自双书交集、法英拼写相同、核心中文义明确重合，并保留双书页码。

题型二现采用两级证据：A级为可定位的 TEM4 完整原句；B级为可定位的 TEM4 原搭配，仅补充形成自然语境所需的最小主语或谓语。近义词与迁移词必须固定在 `T2_RULES`、保持句法可替换，并由审计逐项核对，不允许运行时自由生成。B级题在解析中必须明确标记“基于原书搭配构造”，不得伪称原句。

## 题型四

1. 法英拼写的原始或去重音编辑距离必须为 1–4。
2. 排除仅由法语可预测形态结尾形成的差异，包括 `classer/class` 和 `imaginer/imagine` 类型。
3. 中文题干在当前拼写候选池中不得指向多个法语答案；存在歧义则排除。
4. 目标词在四个题型中全局唯一。

## 生产交付

- 生产 Excel 同时包含便于教研阅读的四个中文题型页，以及后端可直接导入的 `Questionnaire`、`Sections`、`Items`、`Options` 工作表。
- JSON 与 XLSX 必须由同一次生成得到，并通过生产审计脚本验证题量、答案、选项角色、来源页码、拼写距离、形态排除、题干歧义、目标词唯一性和导入表行数。
- 当前生产包代码：`LEXIBRIDGE_FF4_PRODUCTION_20260812`。

## 最大覆盖与状态标记

- “尽量多”定义为：在遵守题型规则、题型间目标词不重复、拼写题无歧义的前提下，完整覆盖“语义批准池 ∪ 拼写合格池 ∪ 客户批准的同源控制池”。
- 生产审计会重新计算这个最大集合，并要求题库目标词集合与其完全相等；少一个词或混入一个不合格词都会审计失败。
- 当前状态必须分层记录：
  - `CONTENT_STATUS=APPROVED`：题目内容与规则审计通过；
  - `COVERAGE_STATUS=MAXIMUM_RULE_COMPLIANT_COVERAGE`：无规则内合格目标词遗漏；
  - `IMPORT_STATUS=READY_FOR_IMPORT_VALIDATION`：文件结构可进入导入验证；
  - `DEPLOYMENT_STATUS=NOT_DEPLOYED`：尚未操作生产数据库或创建 release。
- 后续新增或修订源数据时，必须重新运行完整生成和审计链路；不得手工只改 XLSX 而不更新 JSON、V3 种子和审计报告。
- 当前规则版本为 `FF4_0811_CLIENT_REV2_20260812`。生产包、V3 种子与发布清单必须记录同一规则版本。
- 题型二不得少于 16 道；判断题必须恰好包含 10 道 Vrai 同源控制题，且连续假朋友 F 题不得超过 3 道。
- `production-release-manifest.json` 固定记录交付文件的 SHA-256、题量及状态；上线前应使用该文件核对部署输入未被替换。
- 上线前运行 `python3 scripts/lexi-bridge-ff4-v2/verify_release_manifest.py`，必须得到 `status=PASS` 后方可继续导入验证。
