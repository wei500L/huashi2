# A2 比赛级品牌方向决策：Lexical Cartography

决策日期：2026-08-05  
阶段：品牌叙事与视觉主张已定，尚未进入整站实现  
验证声明：本轮只做静态文档决策，未启动页面，也未运行任何测试、lint、typecheck 或 build。

## 一句话叙事

EF.Transfer 不是“会回答问题的 AI”，而是一张帮助学习者穿越英语到法语迁移地形的可读地图：诊断标出当前位置，训练规划下一段路径，证据解释为什么会走偏，AI 只是测绘工具，不是品牌主角。

这条叙事把已有业务链路变成同一张地图上的连续动作：

`EN 词形/语义 -> 迁移焦点 -> 证据与地形 -> FR 目标表达 -> 训练进展`

## 已确认（A2 规范方向）

### 品牌关键词

**Focus / Route / Terrain / Connection / Evidence / Progress**（焦点、路径、地形、关联、证据、进展）。

图形不再用“魔法、闪光、漂浮玻璃”解释智能，而用可定位、可追踪、可复盘的地图语言解释学习迁移。品牌锚点是一个 **EN↔FR 迁移焦点**：两端词形或短语被一条可读的路线连接，路线经过的节点代表语义、搭配、语法或发音证据。

### 图形隐喻与共享骨架

- **地图底图**：等高线、网格、标记点和方向线；只在需要建立空间关系的区域出现，不铺满每个页面。
- **迁移路线**：从英文起点到法文目标的单条主路径；路径状态区分已走、当前焦点、下一步和受阻。
- **证据图钉**：例句、错误原因、词义差异和保存/提交状态使用可追溯的标记，不用发光边框抢注意力。
- **共享骨架**：三角色共享地图语法、状态语义和可访问性规则，但通过信息密度、默认视图和首要动作区分工作区。
- **层级原则**：每页一个 page title、一个任务锚点；工作台先呈现下一任务/异常/队列，Hero 只留给确有叙事价值的路线页面。

### 颜色方向（语义优先，不锁定色值）

- **主色方向**：深墨色/石墨色文字与线条，承担导航、正文、边界和主要信息层级；优先稳定不透明表面，降低全域玻璃和大面积 blur。
- **辅色方向**：纸张、石灰或雾白表面，配少量低饱和矿物中性色，作为地图底图和分组层，不承担状态含义。
- **来源 English**：暖矿物色（铜、赭石一类），表达起点与已知线索。
- **目标 Français**：冷水域色（青绿、深湖蓝一类），表达目标表达与落点；不模拟国旗配色。
- **迁移/进展**：一条高辨识度的亮色路线（黄绿或金色一类），只用于当前焦点、完成进度和可执行 CTA。
- **语义状态**：锈红/氧化色表示阻塞或错误，苔绿色表示可恢复成功，灰蓝表示中性、历史与未激活。
- **紫色**：降为极少量的辅助强调，不再作为背景、按钮、边框和图表的默认总线。

### 字体气质

主字体采用具有人文气质、开放字腔和清晰重音的无衬线，保证英文、法文长词和中文在同一层级下自然换行；数字、日期、坐标和证据 ID 可用克制的等宽/窄体辅助。避免几何未来感、超宽字距和依赖全大写的“高级感”。字体选择必须先通过中英法真实文案长度与对比度复核，不能以缩小字号解决拥挤。

### 动效节奏

默认静止，只有状态改变才动：路线首次出现时短暂绘制、当前焦点切换时一次强调、提交/保存等状态变化给出可暂停的确认。禁止全局慢过渡、持续流动边框、无限背景动画、指针驱动 3D/磁吸和无业务价值的数字 RAF；所有动效都要覆盖 `prefers-reduced-motion`，低动效下保留静态焦点、颜色和文本说明。

## React Bits 评估：候选与明确排除

| 组件 | 结论 | 适用边界与原因 |
| --- | --- | --- |
| [Topography](https://reactbits.dev/backgrounds/topography) | **候选：最接近品牌锚点** | 适合做低对比、稀疏的地图等高线或路线页底图，能直接表达“地形”。必须静态/低频、可关闭、避开正文和焦点对比，不复制默认紫色背景。 |
| [TrueFocus](https://reactbits.dev/text-animations/true-focus) | **候选：焦点状态** | 适合学生诊断中突出一个迁移词对、错误片段或下一步；不作为全局标题动画，避免遮蔽长法文和关键状态。 |
| [VariableProximity](https://reactbits.dev/text-animations/variable-proximity) | **候选：探索性微交互** | 可在词对/节点探索时表达“靠近焦点”，但只限局部、低强度、键盘可达，并须有静态等价呈现；不能让每个列表项都随指针变形。 |
| [StrokeText](https://reactbits.dev/text-animations/stroke-text) | **明确排除：默认品牌字形** | 轮廓字在双语长标题、低对比表面和小屏上牺牲可读性，且容易回到海报/霓虹装饰语气；不用于 logo、CTA 或数据。 |
| [TextLoop](https://reactbits.dev/text-animations/text-loop) | **明确排除：全局品牌锚点** | 循环口号会替换任务信息、增加认知等待并与 reduced-motion 冲突；比赛演示中也会稀释“迁移地图”的单一记忆点。 |
| [WebThreads](https://reactbits.dev/backgrounds/web-threads) | **候选：关系视图专用** | 可在教师词汇关系/班级迁移网络中作为稀疏连接线，表达关联而非地形；不做全局背景，不用于管理员高密度控制台，避免变成通用科技网络。 |

候选组件都不是本轮实现承诺；先以现有 CSS/DOM 做低保真验证，再决定是否引入依赖。任何组件若无法满足静态降级、长文案、键盘焦点和性能预算，应退回明确排除。

## 三角色差异

| 工作区 | 叙事角色 | 默认视觉与首要动作 |
| --- | --- | --- |
| 学生 `STUDENT_WORKSPACE` | **路线行者**：我在哪一段迁移路线上，下一步去哪？ | 更温暖、留白更充足；突出当前焦点、到期复习、保存状态和可恢复的下一步。可使用一次性的 TrueFocus/路线绘制。 |
| 教师 `TEACHING_WORKSPACE` | **地图编辑者**：哪一片地形让一群人卡住，如何批量改道？ | 中等至高密度；突出队列、班级对比、共享错误地形、干预和批量动作。WebThreads/等高线只服务关系判断。 |
| 管理员 `ADMIN_CONSOLE` | **测绘控制台**：系统在哪些时间、区域和异常上需要审计？ | 最高密度、最中性；突出时间范围、异常、来源、审计线索和 AI 运行状态。禁用 3D、磁吸、持续发光和欢迎式 Hero。 |

## 适合比赛演示的三条关键路径

1. **学生：从误迁移到下一站** —— 选一个英语-法语词对，诊断聚焦错误地形，展开证据图钉，接受推荐训练并看到路线进度更新。
2. **教师：从班级地形到干预** —— 在班级地图中发现共同迁移障碍，按证据分组比较，批量发布一段训练，再回看队列状态和进展。
3. **管理员：从全局异常到可追溯** —— 选择时间范围，定位活跃/完成或 AI 运行异常，沿来源和审计线索下钻；页面用高密度中性表面证明系统可信度。

## 明确不在本轮锁定的事项

- 不锁定具体像素、色值、字体文件、组件 API 或页面换肤方案。
- 不改业务逻辑、API、权限、保存/提交队列、现有 `zh-CN` / `en-US` i18n 契约，也不新增 `fr-FR` UI 契约。
